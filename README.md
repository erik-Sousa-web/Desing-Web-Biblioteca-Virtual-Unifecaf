# 📚 Biblioteca Digital UniFECAF

Projeto desenvolvido para a disciplina de **Design Web**, com o objetivo de criar uma página para a Biblioteca Digital da UniFECAF.

O site foi desenvolvido utilizando HTML e CSS, buscando apresentar uma interface organizada, agradável e adaptável a diferentes tamanhos de tela.

## 🎯 Objetivo do projeto

Criar uma página web que facilite a visualização das categorias de livros e apresente informações sobre a biblioteca, suas unidades e contatos.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub
- GitHub Pages

## 📌 Funcionalidades e seções

O site apresenta as seguintes áreas:

- **Menu de navegação:** acesso às principais seções.
- **Sobre a biblioteca:** apresentação da Biblioteca Digital.
- **Banner:** destaque visual da página.
- **Nossos livros:** apresentação de seis categorias de conhecimento.
- **Unidades:** área destinada às informações das unidades.
- **Contatos:** informações sobre os canais de atendimento.

## 📱 Responsividade

O projeto possui ajustes para diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.

Foram utilizados recursos do CSS para reorganizar os elementos e facilitar a visualização em dispositivos menores.
